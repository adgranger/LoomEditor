## Design decisions (already made — do not change)

- **Key of a PublicAPI line:** strip a leading `static `, `readonly `, `const `, `override `, `abstract `, `virtual `, `~`, `*REMOVED*`. Take the text before ` -> ` and before `(`.
  Replace `LoomEditor.WinUI.Controls.` with `LoomEditor.Avalonia.Controls.` and `LoomEditor.WinUI.` with `LoomEditor.Avalonia.`. Example:
  `LoomEditor.WinUI.Controls.LoomEditor.SetHiddenAreas(System.Collections.Generic.IReadOnlyList<…>! ranges) -> void` → `LoomEditor.Avalonia.Controls.LoomEditor.SetHiddenAreas`.
- **Test:** `missing = winuiKeys − avaloniaKeys − exceptions`. It must equal the pending list exactly. The failure message lists the keys to add to or remove from
  `AvaloniaParityPending.txt`. Keys present in Avalonia but not in WinUI are allowed (for example `GlyphFontFamily`, decision 6).
- **Exceptions at creation:** `LoomEditor.Avalonia.LoomEditor_WinUI_XamlTypeInfo…` (generated by the WinUI XAML compiler) — `# WinUI XAML compiler output`. Nothing else.
- **Pending at creation:** every other WinUI key (generate the file with the test's own reduction, sorted, one per line).
- The smoke test opens a headless `Window` with a `TextBlock`, captures a frame (`CaptureRenderedFrame`), and checks it is not null and has the window size. That proves Skia
  draws in CI on all three OSes.
- `PublicAPI.Unshipped.txt` of Avalonia holds `LoomEditor.Avalonia.LoomEditorStyles` (+ constructor) only.
