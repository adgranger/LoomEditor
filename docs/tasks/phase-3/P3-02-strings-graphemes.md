# P3-02 — Strings: grapheme clusters (`GraphemeIterator`, `nextCharLength`, `prevCharLength`)

- **Status:** done
- **Depends on:** P3-01
- **Size:** M (plus one generated data file)

## Goal

The cursor moves by grapheme cluster: one press of → skips `é` written as `e` + U+0301, a flag, or a family emoji.
Port Monaco's grapheme break machinery exactly: its break table, its tree lookup, and its (deliberately simplified)
break rules. Read `docs/adr/0006-editing-and-text-input.md`, decision 7.

## Design decisions (already made — do not change)

- Read [the phase 3 conventions](README.md) first.
- **Do not use `System.Globalization.StringInfo` or `Rune` enumeration of text elements.** Monaco's rules are not full
  UAX #29 (GB11 and GB12/13 are applied without state, lines 1069–1081), and the cursor must behave like Monaco.
- `GraphemeBreakData.cs`:
  ```csharp
  // <auto-generated> by eng/Generate-GraphemeBreakData.ps1 from microsoft/vscode src/vs/base/common/strings.ts
  // (getGraphemeBreakRawData), commit 0c9c0a4295a9222e12a605537738719455ae3056. Do not edit.
  // Copyright (c) Microsoft Corporation. MIT License.
  namespace LoomEditor.Core.Text;

  internal static class GraphemeBreakData
  {
      public static ReadOnlySpan<int> Raw => [0, 0, 0, 51229, 51255, 12, /* … all 5,637 values … */];
  }
  ```
  The script writes 24 values per line. It fails (non-zero exit code) if the number of values is not a multiple of 3.
  No JSON parsing at run time (Native AOT). The file is exempt from the ~400-line rule because it is generated.
  The header line `// Ported from microsoft/vscode: …` is **not** used for this file: the architecture test only
  checks files that start with `// Ported from` or `// Inspired by`.
- `GraphemeBreakType` is an `internal enum` with exactly these members and values (from lines 1087–1103; only the two
  names with an underscore are changed to PascalCase, because underscores fail the naming analyzers):
  `Other = 0, Prepend = 1, CR = 2, LF = 3, Control = 4, Extend = 5, RegionalIndicator = 6, SpacingMark = 7, L = 8,
  V = 9, T = 10, LV = 11, LVT = 12, ZWJ = 13, ExtendedPictographic = 14`. The table stores these numbers, so the values
  must not change.
- `GraphemeBreakTree` is `internal sealed class` with `static GraphemeBreakTree Instance { get; }` (created once,
  immutable, safe to share between threads) and `GraphemeBreakType GetGraphemeBreakType(int codePoint)`, a line-by-line
  port of lines 1120–1154 (ASCII fast path, then the 1-based heap walk: `nodeIndex = 1`, left child `2 * i`,
  right child `2 * i + 1`, node `i` at `data[3 * i]`, `data[3 * i + 1]`, `data[3 * i + 2]`).
- `GraphemeIterator` is `internal sealed class` wrapping the `CodePointIterator` of P3-01, constructor
  `(string str, int offset = 0)`, members `Offset`, `NextGraphemeLength()`, `PrevGraphemeLength()`, `Eol()`.
- `GetCharContainingOffset` returns a `(int Start, int End)` tuple.
