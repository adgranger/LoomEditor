# P8-29 — `LspClient`: start the server process, initialize, shut down, survive a crash

- **Status:** done
- **Depends on:** P8-28
- **Size:** M
- **Recommended model:** Opus (child process management with redirected stdio on Windows: start failures, a server that dies mid-handshake, a stdout that cannot be cancelled, zombie processes after a failed test; the behavior of a real server cannot be inferred from the fake. On failure — a hang, a leaked process, a platform-specific stdio behavior you cannot explain — stop, do not commit, report what happened, the commands you ran and what you tried)

## Goal

`LspClient` starts a language server process (or wraps any pair of streams), performs the `initialize` / `initialized` handshake with the client capabilities of ADR 0011, exposes what the server can do, answers the server's own requests, reports log messages and diagnostics as events,
shuts the server down politely (and kills it if it does not obey), and turns a crash into a `Faulted` state instead of a hang.

## Design decisions (already made — do not change)

- **`LspServerCommand`** (**public** `sealed record`): `string FileName`, `IReadOnlyList<string> Arguments`, `string? WorkingDirectory = null`, `IReadOnlyDictionary<string, string>? Environment = null` (variables added to the child's environment). XML doc; `<remarks>Threading: immutable.</remarks>`.
- **`LspServerProcess`** (`internal sealed class : IAsyncDisposable`): `static LspServerProcess Start(LspServerCommand command)` — `new Process { StartInfo = { FileName, WorkingDirectory, UseShellExecute = false, CreateNoWindow = true, RedirectStandardInput = true, RedirectStandardOutput = true, RedirectStandardError = true, StandardErrorEncoding = UTF8, ... ArgumentList }}` (`ArgumentList`, never a joined string), then the environment additions;
  `Start()` failures (`Win32Exception`, `InvalidOperationException`, file not found) → `LspServerStartException` (message includes the file name; inner exception kept). Members: `Stream StandardInput` / `StandardOutput` (`process.StandardInput.BaseStream`, `process.StandardOutput.BaseStream`: **raw bytes, no encoding layer**), `int Id`, `bool HasExited`, `int? ExitCode`,
  `event Action<string>? ErrorLine` (a background loop reads standard error line by line until EOF and raises the event for each line, on the loop's thread; also keeps the **last 50 lines** in `IReadOnlyList<string> RecentErrorLines` for diagnostics), `event Action<int>? Exited` (raised once, with the exit code), `Task WaitForExitAsync(CancellationToken)`, `void Kill()` (`Kill(entireProcessTree: true)`, ignores "already exited"),
  `DisposeAsync` (if still running: `Kill()`, wait up to 2 s; dispose the `Process`; never throws). Standard input is **not** closed by the class on its own (the connection owns the streams; disposing the connection closes them).
- **`LspClientOptions`** (`sealed record`): `string ClientName = "LoomEditor"`, `string? ClientVersion = null`, `string? RootUri = null`, `JsonElement? InitializationOptions = null`, `TimeSpan InitializeTimeout = 60 s` (a real server can be slow to start), `TimeSpan ShutdownTimeout = 3 s`.
- **`LspClientState`**: `NotStarted`, `Initializing`, `Running`, `ShuttingDown`, `Stopped`, `Faulted`. `LspClient.State` (volatile read), `event Action<LspClientState>? StateChanged` (raised on the thread that caused the change: possibly the read loop), `Exception? FaultReason`.
- **`LspClient`** (`internal sealed class : IAsyncDisposable`):
  - Constructors/factories: `LspClient(JsonRpcConnection connection, LspClientOptions options, LspServerProcess? process = null)` (the connection is created **and `Start()`ed by the caller**: tests pass a `MemoryPipe` based one) and `static LspClient StartProcess(LspServerCommand command, LspClientOptions options)` (starts the process, wraps its streams in a new `JsonRpcConnection`, starts it, wires `Exited`).
  - `Task<InitializeResult> InitializeAsync(CancellationToken token = default)`: only from `NotStarted` (else `InvalidOperationException`); `State = Initializing`; sends `initialize` with `InitializeParams { ProcessId = Environment.ProcessId, ClientInfo = { Name, Version }, RootUri = options.RootUri, Capabilities = LspClientCapabilities.Create(), InitializationOptions = options.InitializationOptions }`
    through `connection.SendRequestAsync` with a **linked token** that also cancels after `InitializeTimeout`; on success: stores `ServerCapabilities Capabilities`, sends the `initialized` notification (`InitializedParams`), `State = Running`, returns the result. On any failure (error response, timeout, cancellation, connection closed, process exited): `State = Faulted` (`FaultReason` set), the process is killed, the exception is **rethrown** (a timeout as `TimeoutException("The language server did not answer initialize in …")`, with the last stderr lines appended to the message when there is a process).
  - `Task<TResult?> RequestAsync<TParams, TResult>(string method, TParams @params, JsonTypeInfo<TParams> pi, JsonTypeInfo<TResult> ri, CancellationToken token)` and `Task<JsonElement?> RequestRawAsync(string method, JsonElement? @params, CancellationToken token)`: throw `LspClientException("The language server is not running")` unless `State == Running`; otherwise pass through. `void Notify<TParams>(string method, TParams @params, JsonTypeInfo<TParams> pi)`: same state check, **never blocks**, swallows `JsonRpcConnectionClosedException` (the fault is reported by the state).
  - `Task ShutdownAsync(CancellationToken token = default)`: from `Running` only (any other state: returns a completed task); `State = ShuttingDown`; sends `shutdown` (request, null params) waiting at most `ShutdownTimeout`; sends the `exit` notification; waits for the process to exit (if any) for up to `ShutdownTimeout`, then `Kill()`; `State = Stopped`. A failure at any step still ends in `Stopped` and the process killed (never throws for I/O failure; a `token` cancellation propagates after cleanup).
  - `DisposeAsync`: if `Running` → `ShutdownAsync` bounded by 3 s total, whatever happens; then `connection.DisposeAsync()`, `process.DisposeAsync()`; idempotent; ends in `Stopped` unless `Faulted`.
  - **Crash detection**: `connection.Closed` while `State is Initializing or Running` → `State = Faulted`, `FaultReason = exception ?? new LspClientException("The language server closed the connection")` (with the last stderr lines); the process, if any, is killed; `process.Exited` while `Running` does the same (whichever comes first; once). While `ShuttingDown` / `Stopped` / disposed it does nothing.
  - **Events** (raised on the **read loop thread**, documented; the session posts them to the UI thread): `event Action<PublishDiagnosticsParams>? DiagnosticsReceived` (deserialized from `textDocument/publishDiagnostics` with `LspJsonContext.Default.PublishDiagnosticsParams`; a payload that fails to deserialize is ignored), `event EventHandler<LspLogMessageEventArgs>? LogMessageReceived` (`window/logMessage`, `window/showMessage`: `LspLogMessageEventArgs(int Type, string Message, bool IsShowMessage)`), and `event Action<string>? ServerErrorLine` forwarding the process' stderr lines.
    `$/progress`, `window/showDocument`, telemetry and every other notification are ignored.
  - **Capabilities helpers** (computed once after initialize, via `LspUnions`): `bool SupportsCompletion` (`CompletionProvider is not null`), `IReadOnlyList<string> CompletionTriggerCharacters`, `bool SupportsCompletionResolve`, `bool SupportsHover` (`IsEnabled(HoverProvider)`), `bool SupportsDefinition`, `(bool OpenClose, int Change) TextDocumentSync` (from `ParseTextDocumentSync`); all false / empty before `Running`.
  - **Server requests** (`LspClient.ServerRequests.cs`, assigned to `connection.RequestHandler` in the constructor): `workspace/configuration` → a JSON array of `null` with one element per item of `params.items` (an empty array if the shape is unexpected); `client/registerCapability`, `client/unregisterCapability`, `window/workDoneProgress/create`, `window/showMessageRequest` → `null`; `workspace/applyEdit` → `{ "applied": false, "failureReason": "LoomEditor does not apply workspace edits" }`;
    every other method → throws `JsonRpcException(JsonRpcErrorCodes.MethodNotFound, "Method not found: <method>")`. Build the results with `JsonDocument.Parse(...).RootElement.Clone()` of fixed strings (no reflection, no new types).
- `<remarks>Threading: thread-safe; events on the read loop thread; ADR 0011 decision 4.</remarks>`. `LspClientException : Exception` (`internal`).
- Never write to the process' stdin before `initialize` is sent; the client does not send `didOpen` etc. itself (P8-30).
