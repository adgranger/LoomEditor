# P8-27 — The LSP protocol types, source-generated JSON and the union decoders

- **Status:** done
- **Depends on:** P8-26
- **Size:** M
- **Recommended model:** Opus (the exact shape of the LSP JSON — optional members, unions, `null` versus absent — must match what real servers send and must work under Native AOT with source generation; neither is verifiable from this card alone. On failure — a type whose JSON does not round-trip, an AOT / trimming warning you cannot fix without reflection — stop, do not commit, report the type, the JSON and what you tried)

## Goal

The LSP messages the client needs exist as C# types that serialize and deserialize with the source-generated `LspJsonContext`, and the protocol's union-typed values (`hover.contents`, the completion result, the definition result, `documentation`, `textEdit`, `textDocumentSync`, `*Provider: boolean | options`) are decoded by small hand-written functions.
No client behavior yet.

## Design decisions (already made — do not change)

- **Style.** Every type is an `internal sealed class` with `{ get; set; }` properties named in PascalCase (the context's camelCase policy turns `TextDocument` into `textDocument`; a member whose wire name is **not** the camelCase of its C# name has an explicit `[JsonPropertyName("…")]`: there should be none except `JsonRpc`).
  Optional members are nullable (`string?`, `int?`, `X?`) and are **omitted** when null (`DefaultIgnoreCondition = WhenWritingNull`, set by P8-26). Required members are non-nullable with `required` and are always written. Arrays are `T[]` (not `List<T>`; keeps the source generator output small). XML doc on each type (`<summary>` with the spec name).
  Unknown JSON members are ignored when reading (the default: do **not** set `UnmappedMemberHandling`). No type has a constructor with parameters.
- **Union members are `JsonElement?`** (ADR 0011 decision 3), decoded by `LspUnions` (below): `ServerCapabilities.TextDocumentSync`, `.HoverProvider`, `.DefinitionProvider`, `LspCompletionItem.Documentation`, `.TextEdit`, `LspHover.Contents`; and request / response ids stay `JsonElement`. The completion and definition **results** are `JsonElement?` at the call site (P8-31, P8-33 and P8-34 call the decoders).
- **Constants** (`LspConstants.cs`, `internal static class` per group, `const int` / `const string`, XML doc names the spec section): `LspCompletionItemKind` (`Text = 1` … `TypeParameter = 25`, the 25 LSP values), `LspInsertTextFormat` (`PlainText = 1`, `Snippet = 2`), `LspDiagnosticSeverity` (`Error = 1`, `Warning = 2`, `Information = 3`, `Hint = 4`),
  `LspDiagnosticTag` (`Unnecessary = 1`, `Deprecated = 2`), `LspCompletionItemTag` (`Deprecated = 1`), `LspCompletionTriggerKind` (`Invoked = 1`, `TriggerCharacter = 2`, `TriggerForIncompleteCompletions = 3`), `LspMessageType` (`Error = 1`, `Warning = 2`, `Info = 3`, `Log = 4`), `LspTextDocumentSyncKind` (`None = 0`, `Full = 1`, `Incremental = 2`), `LspMarkupKind` (`PlainText = "plaintext"`, `Markdown = "markdown"`), `LspPositionEncoding` (`Utf16 = "utf-16"`).
  `LspMethods` (`const string`): `Initialize = "initialize"`, `Initialized = "initialized"`, `Shutdown = "shutdown"`, `Exit = "exit"`, `DidOpen = "textDocument/didOpen"`, `DidChange = "textDocument/didChange"`, `DidClose = "textDocument/didClose"`, `PublishDiagnostics = "textDocument/publishDiagnostics"`, `Completion = "textDocument/completion"`, `CompletionResolve = "completionItem/resolve"`,
  `Hover = "textDocument/hover"`, `Definition = "textDocument/definition"`, `CancelRequest = "$/cancelRequest"`, `LogMessage = "window/logMessage"`, `ShowMessage = "window/showMessage"`, `ShowMessageRequest = "window/showMessageRequest"`, `WorkspaceConfiguration = "workspace/configuration"`, `RegisterCapability = "client/registerCapability"`, `UnregisterCapability = "client/unregisterCapability"`,
  `WorkDoneProgressCreate = "window/workDoneProgress/create"`, `ApplyEdit = "workspace/applyEdit"`.

- **`LspUnions`** (`internal static class`; every decoder takes a `JsonElement?` / `JsonElement`, never throws on malformed input: it returns the "nothing" value):
  - `static (bool OpenClose, int Change) ParseTextDocumentSync(JsonElement? value)`: a number `n` → `(true, n)` (LSP: a number means `TextDocumentSyncKind` and open/close notifications are sent: Monaco-like clients treat it as `openClose = true`); an object → `OpenClose = openClose == true`, `Change = change` as number (default 0); anything else / null → `(false, 0)`.
  - `static bool IsEnabled(JsonElement? provider)`: `true` for JSON `true` and for any object, `false` otherwise (including absent and `false`).
  - `static IReadOnlyList<LspCompletionItem> ParseCompletionResult(JsonElement? result, out bool isIncomplete)`: absent / null → empty and `isIncomplete = false`; an array → the items (each deserialized with `LspJsonContext.Default.LspCompletionItem`, an item that fails to deserialize is skipped), `isIncomplete = false`; an object → `items` and `isIncomplete` (`true` only for JSON `true`).
  - `static IReadOnlyList<HoverContentPart> ParseHoverContents(JsonElement contents)` with `internal readonly record struct HoverContentPart(string Value, bool IsMarkdown)`: a **string** (`MarkedString` of the string form) → `(value, true)` (VS Code treats it as markdown); an object with `language` and `value` (`MarkedString`) → ``("```" + language + "\n" + value + "\n```", true)``;
    an object with `kind` and `value` (`MarkupContent`) → `(value, kind == "markdown")`; an array → the concatenation of its elements decoded this way; anything else → empty. Empty values are dropped.
  - `static string? ParseDocumentation(JsonElement? documentation, out bool isMarkdown)`: a string → `(s, false)`; an object with `kind` / `value` → `(value, kind == "markdown")`; else `null`.
  - `static (LspRange? Insert, LspRange? Replace, string? NewText) ParseTextEdit(JsonElement? textEdit)`: an object with `range` → `(range, range, newText)`; an object with `insert` and `replace` → `(insert, replace, newText)`; else `(null, null, null)`.
  - `static IReadOnlyList<LspLocationLink> ParseDefinitionResult(JsonElement? result)`: absent / null → empty; an object with `uri` and `range` (a `Location`) → one link `(TargetUri = uri, TargetRange = range, TargetSelectionRange = range, OriginSelectionRange = null)`; an array whose elements are `Location`s or `LocationLink`s (distinguished per element by the presence of `targetUri`) → the links, in order, skipping malformed elements.
- **Context.** `LspJsonContext` gets `[JsonSerializable(typeof(X))]` for every **root** type used as a request / notification parameter or a result: `InitializeParams`, `InitializeResult`, `InitializedParams`, `DidOpenTextDocumentParams`, `DidChangeTextDocumentParams`, `DidCloseTextDocumentParams`, `PublishDiagnosticsParams`, `CompletionParams`, `LspCompletionItem`, `LspCompletionList`, `TextDocumentPositionParams`, `LspHover`, `LspLocation`, `LspLocationLink`, `CancelParams`, `LogMessageParams`, `ShowMessageParams` (+ the envelope types of P8-26). Nested types are generated automatically.
- Headers: none (nothing ported). `<remarks>Threading: pure and thread-safe.</remarks>` on `LspUnions`.
