# P8-28 — The fake language server (test double) and its test host

- **Status:** done
- **Depends on:** P8-27
- **Size:** M

## Goal

`LoomEditor.Lsp.FakeServer` is a deterministic LSP server that speaks the real protocol over stdio (or over two in-memory streams): it keeps the open document, answers `initialize`, completion (with trigger character `.`), resolve, hover and definition, publishes diagnostics, and can misbehave on demand (delays, crashes, noise on stderr).
Every automated LSP test uses it, so CI never needs a real language server. This card also writes the test host that starts it in process or as a child process.

## Design decisions (already made — do not change)

- **Structure.** `public sealed partial class FakeLanguageServer(Stream input, Stream output, FakeServerOptions options)`: `Task<int> RunAsync(CancellationToken token)` reads messages with `LspMessageReader`, writes with `LspMessageWriter` (through one lock-protected `WriteAsync` helper: the server also sends notifications from the request handlers), handles each message **sequentially in arrival order** except delayed requests (below), and returns the exit code (0 after `shutdown` then `exit`; 1 for `exit` without `shutdown`; 0 when the input ends after a `shutdown`; 1 when it ends otherwise).
  `public string DocumentText`, `public int DocumentVersion`, `public string? DocumentUri` (thread-safe getters for the tests), `public IReadOnlyList<string> ReceivedMethods` (every method name received, in order, snapshot copy). The class uses only types of `LoomEditor.Lsp` (internal: `InternalsVisibleTo` was added in P8-24) and no reflection.
- **`FakeServerOptions`** (`sealed record`, with `static FakeServerOptions Parse(string[] args)` for the console): `string Sync = "incremental"` (`--sync=none|full|incremental`), `int DelayMs = 0` (`--delay=<ms>`: wait this long before answering completion, resolve, hover and definition requests), `string? ExitOn = null` (`--exit-on=<method>`: exit the process with code 3 immediately on receiving that method, no response),
  `string? Stderr = null` (`--stderr=<text>`: write the text and a newline to standard error at start), `bool Incomplete = false` (`--incomplete`: the completion list has `isIncomplete: true`), `bool Chatty = false` (`--chatty`: the server-initiated messages below). Unknown arguments are ignored. In process, tests build the record directly.
- **Lifecycle.** Before `initialize`: a request gets the error `ServerNotInitialized` (-32002) `Server not initialized`; notifications are ignored. `initialize` → `InitializeResult { Capabilities = { PositionEncoding = "utf-16", TextDocumentSync = { openClose: true, change: <0|1|2 per options.Sync> } as a JSON object, CompletionProvider = { TriggerCharacters = ["."], ResolveProvider = true },
  HoverProvider = true, DefinitionProvider = true }, ServerInfo = { Name = "LoomEditor.FakeServer", Version = "1.0" } }` (the union members are built as `JsonElement` with `JsonDocument.Parse`, no reflection); a second `initialize` → error `InvalidRequest` (-32600). `initialized` sets the flag (and with `Chatty`: see below). `shutdown` → result `null`, sets the shutdown flag; every later request except `shutdown`... → error `InvalidRequest` (-32600) `Server is shutting down`. `exit` ends `RunAsync`.
  An unknown request → `MethodNotFound` (-32601); an unknown notification is ignored. A `$/cancelRequest` for a delayed request: see below.
- **Documents** (one document at a time). `textDocument/didOpen` stores `uri`, `languageId`, `version`, `text`, then publishes diagnostics. `didChange`: sets the version; for each change **in order**: no `range` → the text is replaced; with `range` → the substring between the two positions (UTF-16 offsets computed from lines split on `\n`, `\r\n`, `\r`: the position `character` is a UTF-16 index inside the line, a `character` beyond the line length is clamped to the line length, a `line` beyond the last line to the end of the document) is replaced by `text`. Then diagnostics are published.
  A change for another `uri` or a stale version (`version <= current`) is **ignored and recorded** in `ReceivedMethods` as `didChange(ignored)`. `didClose` clears the document and publishes an empty diagnostics list for the uri.
- **Diagnostics** (published after every open / change / close as `textDocument/publishDiagnostics` with `{ uri, version, diagnostics }`): scan each line for the whole words (`[A-Za-z_][A-Za-z0-9_]*`, ordinal, case-sensitive) in this table; every occurrence is one diagnostic with `source: "fake"`, range = the word, message `Found <WORD>`:
  `ERROR` → severity 1, `code` the string `"FAKE001"`; `WARN` → severity 2, `code` the number `2`; `INFO` → severity 3, no code; `HINT` → severity 4; `UNUSED` → severity 4 with `tags: [1]`; `OLD` → severity 4 with `tags: [2]`. A document without these words publishes `diagnostics: []`. `version` is the document version.
- **Completion** (`textDocument/completion`, params `textDocument`, `position`, `context`): the word being typed is the identifier prefix that ends at the position (`prefixRange`, may be empty). If `context.triggerCharacter == "."`: the items are `Length` (kind 10 Property), `Count` (10), `ToString` (kind 2 Method, `commitCharacters: ["("]`), `Equals` (2, `commitCharacters: ["("]`), each with a **`textEdit` of the `insert`/`replace` form**: insert = `[position, position]`, replace = `[position, end of the identifier at the position]`, `newText` = the label.
  Otherwise the items are every **distinct** word of the document (`[A-Za-z_][A-Za-z0-9_]{1,}`, so at least two characters, **excluding the word that ends exactly at the position**), sorted ordinal, kind 1 (Text), `insertText` = the label, **no** `textEdit`; plus the four keywords `if`, `else`, `for`, `class` (kind 14) with `insertText` and `preselect: true` for `if` only. Every item has `sortText = label`, `filterText` absent, and `data = { "label": <label>, "n": 1 }`.
  The result is `{ isIncomplete: <options.Incomplete>, items }` (the object form). Items with the `.` trigger come **first**. `Incomplete` makes `isIncomplete` true.
- **Resolve** (`completionItem/resolve`): returns the received item with `detail = "detail of <label>"` and `documentation = { kind: "markdown", value: "**<label>** documentation" }`; for the label `Length` it also has `additionalTextEdits = [ { range: (0,0)-(0,0), newText: "// resolved\n" } ]`. `data` is returned unchanged.
- **Hover** (`textDocument/hover`): `word` = the identifier containing the position (a position at the end of an identifier counts as inside it); none → result `null`; else `{ contents: { kind: "markdown", value: "```fake\n<word>\n```\nHover for **<word>**" }, range: <the word range> }`.
- **Definition** (`textDocument/definition`): `word` as for hover; none → `null`. `word == "external"` → a single `Location` `{ uri: "file:///other/file.txt", range: (0,0)-(0,8) }` (the shape `Location`, to test an `ILocationOpener`). Otherwise search the document for the **first** line containing `def <word>` (a single `Location` at the word of that declaration) or `class <word>` (an **array** with one `LocationLink`: `originSelectionRange` = the word at the request position, `targetUri` = the document uri, `targetRange` = the whole line (from column 0 to the line end), `targetSelectionRange` = the declared word),
  matched on whole words, `def` checked before `class`; not found → `null`.
- **Delays and cancellation.** With `DelayMs > 0`, completion / resolve / hover / definition are answered by a task started for the request (`Task.Run`) that waits `DelayMs` ms and then writes the response; the read loop keeps reading. A `$/cancelRequest` with the id of a request that is still waiting makes it answer with the error `RequestCancelled` (-32800) **immediately** instead of the result (and only once). `ReceivedMethods` records `$/cancelRequest`.
- **`--chatty`** (server-initiated messages, after `initialized`): a notification `window/logMessage` `{ type: 3, message: "fake server ready" }`; a request `workspace/configuration` with the **string id** `"cfg-1"` and `params: { items: [ { section: "fake" } ] }` (the client must answer with an array); a request `client/registerCapability` (id `"reg-1"`, `params: { registrations: [] }`);
  a request `window/workDoneProgress/create` (id `"wdp-1"`, `params: { token: "t1" }`); a request `workspace/applyEdit` (id `"edit-1"`, `params: { edit: { changes: {} } }`); a notification `window/showMessage` `{ type: 2, message: "fake warning" }`. The responses the server receives are recorded as `response(<id>)` in `ReceivedMethods`, and `public JsonElement? LastResponseResult(string id)` returns the `result` the client sent for a server request id (null if none or if it was an error).
- **Misbehavior.** `--exit-on=<method>`: `Environment.Exit(3)` when running as a process (`Program.cs` passes `exitProcess: true`); in process the loop returns `3`. `--stderr=<text>` is written at the very start. Standard output carries **only** protocol frames (the server never uses `Console.Out`); diagnostics for humans go to standard error.
- **`FakeServerHost`** (test helper, README §6): `static FakeServerHost StartInProcess(FakeServerOptions? options = null)` — creates a `MemoryPipe` (P8-24), starts `FakeLanguageServer.RunAsync` on `Task.Run`, creates and starts a `JsonRpcConnection` on the client side; members `JsonRpcConnection Connection`, `FakeLanguageServer Server`, `Task<int> ServerExit`, `List<(string Method, JsonElement? Params)> Notifications` (recorded from `NotificationReceived`, with a `WaitForNotificationAsync(string method, TimeSpan timeout)`), `ValueTask DisposeAsync()` (disposes the connection and waits for the server task with a timeout).
  `static FakeServerHost StartProcess(FakeServerOptions? options)` — the same but the server is a child process started with `FakeServerLocator` (below), its stdin / stdout become the connection's streams, its stderr is collected in `StderrText`; `DisposeAsync` kills the process if it is still running. `FakeServerLocator.GetStartInfo(string[] args)`: the apphost `LoomEditor.Lsp.FakeServer.exe` (Windows) / `LoomEditor.Lsp.FakeServer` (others) next to the test assembly if it exists, else `dotnet` with `LoomEditor.Lsp.FakeServer.dll` from `AppContext.BaseDirectory`;
  neither exists → `FileNotFoundException` with the paths tried. **If the child process cannot be started on this machine (neither file exists or the process dies at once), stop and report: the next cards depend on it.** A `FakeServerHost` helper `Initialize()` sends `initialize` (with `LspClientCapabilities.Create()`, `processId = null`, `rootUri = null`) then the `initialized` notification and returns the `InitializeResult`.
